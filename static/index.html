Connect the live API

Use your local stack or hosted API and its private credentials. The free host may take about a minute to wake. Tokens stay in memory, never browser storage.

Remote APIs require HTTPS. HTTP is allowed only for localhost. Any running preview trip is marked interrupted when you connect.
